# Bejewelled Stories

A luxury e-commerce website for traditional Indian pearl jewelry with a modern touch.

## Deployment to Vercel

This project is configured for easy deployment to Vercel. Follow these steps to deploy:

### Option 1: Deploy from the Vercel Dashboard

1. Log in to your Vercel account at [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import your Git repository (GitHub, GitLab, or Bitbucket)
4. Select the "bejewelled-stories" repository
5. Keep the default settings (they should be automatically detected)
6. Click "Deploy"

### Option 2: Deploy using the Vercel CLI

1. Install the Vercel CLI:
   ```
   npm install -g vercel
   ```

2. Navigate to your project directory:
   ```
   cd bejewelled-stories
   ```

3. Run the deployment command:
   ```
   vercel
   ```

4. Follow the prompts to log in and configure your deployment

### Environment Variables

No environment variables are required for basic deployment.

## Development

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

To build the project for production:

```bash
npm run build
```

## Start

To start the production server:

```bash
npm start
```

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `/src/app`: App router pages and layouts
- `/src/components`: Reusable UI components
- `/src/lib`: Utility libraries and API clients
- `/src/styles`: Global styles and Tailwind configuration
- `/src/utils`: Helper functions and utilities
